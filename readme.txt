A Gutenberg block for presenting download information, with correct link handling and structured data.

== Description ==

Lunar Download gives authors one consistent way to show a download entry, such as a livery, a mod, or any other file: details that differ for every file, one or more download buttons, correct link attributes, and structured data for search engines. The author writes every detail by hand; the plugin keeps the structure, the consistency, and the output in order.

It is designed to blend into your site. Typography and colors come from your theme, and there is no separate dark mode to maintain.

**Status**

Lunar Download is under development. The Download Info block can be inserted in the editor, but it does not print anything on the front end yet, and the tabs of the settings screen are still empty.

== Installation ==

1. Upload the `lunar-download` folder to the `/wp-content/plugins/` directory, or install the plugin from the Plugins screen.
2. Activate the plugin through the Plugins screen.
3. Go to Settings > Lunar Download to see the plugin settings.
